# Google Fonts submission review

Threadline has six named families: Running, Satin, Applique, Plain, Woven, and Chain.
Running and Plain have Regular.
Satin, Applique, and Chain have Regular and Bold.
Woven has Regular and ExtraBold.
Each font maps 352 characters and covers all 319 codepoints in the Google Fonts Latin Core set as of 9 November 2026.
The family names had no exact match on [fontdata name check](https://namecheck.fontdata.com/) on 9 November 2026.
The editable paths, UFO sources, TTF exports, WOFF2 exports, OFL license, author contacts, and one-command build are in this repository.
The project discloses AI assistance in `CONTRIBUTORS.txt`.

## Before submission

- Review the outlines, spacing, accents, and small-size specimens as a designer.
- Confirm the copyright authors and that no larger retail version of any family exists.
- Run the network-dependent Google Fonts checks when the project is staged in the Google Fonts repository.
- Get Shravanpuri Goswami's approval before opening any Google Fonts issue or pull request.

The [Google Fonts issue template](https://github.com/google/fonts/blob/main/.github/ISSUE_TEMPLATE/1_add-font.md) and [upstream guide](https://googlefonts.github.io/gf-guide/upstream.html) define the submission requirements.
