# Design and release checklist

- [x] Draw an original uppercase, lowercase, numeral, and punctuation proof.
- [x] Export two scalable TTF styles from editable drawings.
- [x] Render and inspect a specimen on a light cloth background.
- [ ] Redraw lowercase glyphs at text sizes and refine every curve and join.
- [ ] Tune side bearings and kerning with real words and UI labels.
- [ ] Add GF Latin Core characters, accents, and language proofs.
- [ ] Export UFO source files and make a one-command production build.
- [ ] Run FontBakery with the Google Fonts profile and resolve its findings.
- [ ] Review outlines and test in browsers, Godot, Android, and print.
- [ ] Ask a type designer to review the family before the first public release.
- [ ] Submit to Google Fonts and other galleries after the family passes review.

Google Fonts asks for complete editable sources, scalable TTF builds, GF Latin Core coverage, and FontBakery QA.
The project requirements are described in the [Google Fonts onboarding guide](https://googlefonts.github.io/gf-guide/onboarding.html) and [production guide](https://googlefonts.github.io/gf-guide/production.html).
